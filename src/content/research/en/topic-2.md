Antibody language models can not only identify and classify existing antibody sequences, but also
generate new ones. If we can evaluate how well generated sequences reflect the response to a target
antigen, this opens paths toward antibody design and immune response analysis.

#### Approach

Antigen information is given as a prompt to an antibody language model, which generates sequences.
Those generated sequences are then used to evaluate antigen-specific immune responses.
